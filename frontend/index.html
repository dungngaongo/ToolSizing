Module Kafka

CHỌN PHƯƠNG PHÁP TÍNH TOÁN

PHƯƠNG ÁN A: TÍNH THEO LƯU LƯỢNG

Kiểm tra Monitor (Grafana/JMX) thông số BytesInPerSec

Công thức tính toán

  • Tổng Disk Cluster:
    D = A × 3600 × T × R × C × 1.1 / 0.8 (MB)
  • RAM/Server:
    RAM = S × R / N + 8GB
    (S = A × 1800, chọn N sao cho 16 < RAM < 64)
  • Disk/Server: D / N
  • vCPU/Server:
    A < 50MB/s: 8 vCPU
    A ≥ 50MB/s: 16 vCPU

Lưu ý

  • N tối thiểu = 3 (Kafka cluster)
  • RAM mục tiêu ~32GB (16 < RAM < 64)
  • Zookeeper/KRaft: 3 node tách riêng

PHƯƠNG ÁN B: TÍNH TUYẾN TÍNH (EXISTING SYSTEM)

Dành cho trường hợp dự án muốn "bê nguyên" cụm cũ lên hoặc mở rộng. Nhập thông tin các Kafka Broker hiện tại.
